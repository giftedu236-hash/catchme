# 캐치미 부산

부산 해양 외래종 신고·수색 지원 시연 웹앱입니다. 사진 기반 종 후보 판별에는 **Gemini 이미지 API**를, 해류 정보에는 **국립해양조사원 조류예보 API**를 사용하도록 준비했습니다.

## 선택한 API

- **종 판별:** Gemini API — Google AI Studio에서 API 키를 발급받아 사진을 함께 보낼 수 있습니다. Google Lens 화면을 비공식적으로 수집하지 않습니다.
- **해류:** 국립해양조사원 `GetCrntFcstFldEbbApiService` — 요청에는 `serviceKey`와 `obsCode`가 필요합니다.

## 수색 범위 계산 방식

앱은 태종대 남측 예보지점(`21LTC01`)의 공공 API 응답에서 다음 실제 값을 사용합니다.

- `predcDt`: API가 제공한 예측 시각
- `crdir`: 유향(도)
- `crsp`: 유속(cm/s)

계산식은 아래와 같습니다.

`예상 수색거리(km) = (유속(cm/s) × 0.036 × 발견 시각부터 현재까지 경과시간 × 종별 표류계수) + 종별 자력 이동거리`

유향은 북·북동·동 등의 16방위로 바꿔 지도에 표시합니다. 종별 표류계수와 자력 이동거리는 제출용 잠정값이므로, 실제 기관 운영 전에는 해양생물 전문가 검토가 필요합니다.

## 가장 쉬운 실행 방법: 내 PC에서 열기

Vercel·GitHub 가입 없이도 쓸 수 있습니다.

1. [start_local.bat](./start_local.bat)을 더블클릭합니다.
2. 처음 실행하면 `.env.local` 파일이 자동으로 열립니다.
3. 다음 두 줄의 `replace_...` 부분에 본인 키를 붙여 넣고 저장합니다.
   - `GEMINI_API_KEY`: Google AI Studio에서 받은 새 키
   - `DATA_GO_KR_SERVICE_KEY`: 공공데이터포털 일반 인증키
4. `start_local.bat`을 한 번 더 더블클릭합니다.
5. 브라우저가 열리면 사진 AI 판별과 조류 API를 사용할 수 있습니다.

`.env.local`은 본인 컴퓨터에만 남고 GitHub에는 올라가지 않습니다. 키를 채팅·코드·GitHub에 올리지 마세요.

## 인터넷에 배포하는 방법

정적 화면은 GitHub Pages에서도 표시됩니다. 다만 AI와 공공 API 키를 안전하게 숨기려면 **Vercel 배포**가 필요합니다.

1. 이 폴더를 GitHub 저장소에 올립니다. `.env` 파일은 올리지 않습니다.
2. Vercel에서 저장소를 Import합니다. `api/` 폴더가 서버리스 함수로 자동 배포됩니다.
3. Vercel의 **Project Settings → Environment Variables**에 `.env.example`의 세 값을 입력합니다.
4. 배포된 주소에서 사진을 올리고 `AI로 종 후보 확인하기`를 누릅니다.

로컬의 정적 파일만 열면 AI API가 없으므로 시연용 후보가 표시됩니다. 배포 후에는 `/api/identify`가 Gemini를 호출합니다.

## 안전 기준

- AI 후보는 확정 판정이 아니며, 최종 대응은 담당자·전문가가 검토합니다.
- 원본 사진은 AI 판별 요청에만 사용하도록 설계했습니다. 별도 저장·공개 기능은 넣지 않았습니다.
- API 키는 코드, 브라우저 개발자 도구, GitHub 저장소에 노출되면 안 됩니다.
